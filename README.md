# BankSystem

A simple console-based banking system written in C# as a learning project.

## About the Project

BankSystem is a small application that simulates basic banking operations. It is being developed step by step to improve my C# programming skills.

## Version 0.1

### Features

- Display account balance
- Deposit money
- Withdraw money
- Validate transaction amounts
- Prevent withdrawals exceeding the available balance
- Navigate through a console menu
- Exit the application

## Technologies

- C#
- Visual Studio

## Learning Goals

- Practice loops and conditional statements
- Handle user input
- Implement basic input validation
- Develop problem-solving skills
- Learn to build applications incrementally

## Planned Features

- Code refactoring using methods
- Account management with classes
- Transaction history
- Multiple bank accounts
- Money transfers
- Data persistence

## Project Status

**Version:** 0.1
