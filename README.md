# BankSystem

A console-based banking system written in C# as a learning project.

## About the Project

BankSystem is a small application that simulates basic banking operations. The project is developed incrementally to improve C# programming skills and learn how to build applications step by step.

## Version 0.1 — Basic Banking Operations

### Features

- Display the current account balance
- Deposit money
- Withdraw money
- Validate transaction amounts
- Prevent withdrawals exceeding the available balance
- Navigate through a console menu
- Exit the application

## Technologies

- C#
- Visual Studio

## Learning Goals

- Practice loops and conditional statements
- Handle user input
- Implement input validation
- Improve problem-solving skills
- Learn to structure and develop applications incrementally

## Planned Features

- Refactor code using methods
- Introduce an `Account` class
- Add transaction history
- Support multiple bank accounts
- Implement money transfers
- Save and load data from files
- Add automated tests

## Project Status

- **Current version:** 0.1
- **Status:** In development

## Disclaimer

This project is intended for educational purposes only. It is a learning simulation and does not implement real banking or security functionality.
